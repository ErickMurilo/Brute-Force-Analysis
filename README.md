# SSH Brute-Force-Analysis


Projeto de simulação de ataque de brute force SSH utilizando Hydra e análise de tráfego no Wireshark em ambiente laboratorial controlado.

O objetivo do projeto foi identificar padrões característicos de autenticação automatizada e comportamento de força bruta através da análise da camada TCP e do serviço SSH.

- Ataque de dicionário com Hydra
- Captura de tráfego SSH
- Análise de Handshake TCP
- Inspeção de portas dinâmicas
- Identificação de conexões SYN sequenciais
- Análise hexadecimal de pacotes
- Identificação de IOC (Indicators of Compromise)

## Ferramentas Utilizadas
- Windows Host
- Kali Linux Virtual Machine
- Wireshark
- Hydra
- SSH
- Linux Terminal

## Obejtivo
O objetivo central desta investigação é analisar e caracterizar os padrões heurísticos e comportamentais de um ataque de Brute Force no Wireshark
